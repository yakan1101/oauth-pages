Privacy Policy

Family Drive Automation is a private, non-commercial tool used only by one family.

Data accessed

The tool accesses Google Drive only for the family member's own account that authorized it, in order to save and organize that account's own files.

How data is used

  • Data is used only to perform the file organization requested by the account owner.
  • Data is processed on the family's own computer.

Sharing

No data is sold, shared with, or transferred to any third party. Data is not used for advertising.

Storage and deletion

The tool does not keep copies of Google user data outside the account owner's own Google Drive and own computer. Access can be revoked at any time from the Google Account settings page (Security > Third-party access).

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
